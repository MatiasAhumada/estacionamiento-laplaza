# Guía de la demo

Leer antes de trabajar cada ticket: [convenciones técnicas](convenciones-tecnicas-base.md), [dominio](dominio-funcional.md), [flujos](flujos-operativos.md), [arquitectura](arquitectura-frontend.md), [diseño](diseno-ui.md), [modelo de datos](modelo-datos-demo.md), [plan](plan-implementacion.md) y [especificaciones de tickets](tickets-demo.md). La [investigación](investigacion-repositorio.md) distingue lo existente de lo propuesto. [Decisiones y futuro](decisiones-y-futuro.md) registra límites y dudas.

La planificación de Jira se ubica en el proyecto `COD`, bajo la épica «Estacionamiento La Plaza — Demo Frontend Funcional». Esta investigación no agrega páginas ni lógica de negocio. Toda ruta, tipo o componente marcado **propuesto** debe crearse en su ticket.

Orden: base visual y estado compartido; terminal e ingreso; ticket de ingreso; cálculo y cobro; caja; administración y reportes; integración y validación.
